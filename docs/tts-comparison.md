## Что из этого следует

1. **Женский русский голос — только irina, и лицензия у него неизвестна.** CC0 есть лишь у мужских голосов. Фразы звучат от её лица («я рада»), поэтому женский голос важен.
2. **espeak-ng под GPL-3.0.** Для семейного приложения, которое никто не распространяет, это не мешает. Если проект когда-нибудь станет публичным, весь код должен быть совместим с GPL.
3. **Объём:** минимальный набор (raya 28 МБ + irina 63 МБ + движок ≈30 МБ) ≈ 120 МБ при первой загрузке. С issai-high ≈ 220 МБ.
4. **GitHub не примет issai-high** (больше 100 МБ на файл) без Git LFS. Предлагаю не класть модели в git: скрипт `scripts/fetch-voices.ts` скачивает их при сборке в `public/voices/`, а service worker кэширует.
5. **Запасной путь для казахского** (если синтез не подойдёт): записи голосом близких + склейка заранее записанных фрагментов. Он есть в плане как третий источник.

## Что нужно, чтобы закончить сравнение

Открыть в настройках среды доступ к `us.aws.cdn.hf.co` (или выдать модели файлами). Тогда я синтезирую 5 тестовых фраз на каждом голосе, пришлю аудио, замерю скорость в Chromium и заполню таблицу.

Тестовые фразы:

- ru: «Я хочу пить.» «У меня сильно болит голова.» «Позвони Алии, пожалуйста.» «Мне грустно, потому что Алия давно не звонила.» «Вы хотите увидеть Ерлана?»
- kk: «Мен су ішкім келеді.» «Басым қатты ауырып тұр.» «Әлияға қоңырау шалшы.» «Көңілім жоқ, себебі Әлия көптен бері хабарласпады.» «Ерланды көргіңіз келе ме?»
