# Локальный синтез речи: сравнение голосов

Все голоса — Piper, работают прямо в браузере без сети. Образцы — 5 тестовых фраз на каждый голос, синтезированы тем же кодом, что в приложении (воркер `public/workers/tts-worker.js`, Chromium), с выравниванием громкости. Скорость и размер я замерил, естественность звучания оценивает слушатель.

Тестовые фразы:

- ru: «Я хочу пить.» «У меня сильно болит голова.» «Позвони Алии, пожалуйста.» «Мне грустно, потому что Алия давно не звонила.» «Вы хотите увидеть Ерлана?»
- kk: «Мен су ішкім келеді.» «Басым қатты ауырып тұр.» «Әлияға қоңырау шалшы.» «Көңілім жоқ, себебі Әлия көптен бері хабарласпады.» «Ерланды көргіңіз келе ме?»

## Скорость на планшете

Отсюда на настоящем планшете не замерить. Оценка по типичной разнице в скорости однопоточного WASM:

- **iPad** последних лет — примерно как на сервере: irina 0,5–1 с на фразу, raya 0,3–0,6 с.
- **Недорогой Android-планшет** — в 2–3 раза медленнее: irina 1–2,5 с, raya 0,7–1,8 с, issai-high 6–20 с.

Настоящую цифру покажет «Общие настройки» → «Проверка голоса». Чтобы задержку было меньше слышно:

- следующая фраза синтезируется, пока звучит текущая;
- фраза из «Так?» после «Да» звучит сразу: она уже синтезирована;
- синтезированные фразы хранятся на планшете (до 400), частые звучат сразу;
- пока модели грузятся после запуска, звучит голос устройства.

## Выбор по умолчанию и почему

- **Русский — irina.** Единственный женский русский голос, а фразы звучат от её лица («я рада»). Риск — неизвестная лицензия данных. Для семейного приложения без распространения он невелик. Если нужна чистая лицензия — denis (CC0, мужской).
- **Казахский — raya.** Женский, быстрый, маленький. Частота 16 кГц: звучит глуше русского, но разборчиво. issai-high звучит богаче, но на недорогом планшете синтез фразы займёт 6–20 с — для разговора слишком долго.

Как поменять: исправить `voices.config.json` (путь голоса из `rhasspy/piper-voices`, номер голоса, темп), затем `npm run voices` и `npm run build`.

## На что обратить внимание при прослушивании

- Ударения в именах и падежных формах: «Алии», «Ерлана».
- Казахские звуки ә, ө, ү, ұ, қ, ғ, ң, і — не звучат ли по-русски.
- Не слишком ли быстро для неё. Если быстро — увеличить `lengthScale` у этого голоса.
- Если какое-то имя плохо звучит в любом голосе, лучше записать его своим голосом в карточке человека: запись всегда важнее синтеза.

## Как повторить замер

```bash
npm run voices && npm run build
mkdir -p out/bench   # положить сюда *.onnx и *.onnx.json сравниваемых голосов
npx http-server out -p 3101 -c-1 -s &
WAV_DIR=/путь/к/образцам node --experimental-strip-types scripts/bench-voices.ts
```

`ONLY=raya` — замерить один голос, `LENGTH_SCALE=1.6` — другой темп.
