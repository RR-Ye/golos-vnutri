# Голос внутри

Приложение для планшета, которое помогает человеку с афазией сказать то, что он думает. Бабушка нажимает на картинки, выбирает лицо, показывает, где болит, или говорит своё слово. Приложение угадывает мысль, уточняет вопросами «да / нет» и произносит готовую фразу по-русски и по-казахски. Бабушка повторяет её вслух — это и разговор, и занятие для речи.

Всё работает без интернета и хранится только на этом планшете. Никаких облачных сервисов, нейросетей, аккаунтов и рекламы.

## Как это выглядит для неё

1. Она нажимает тему: «Потребности», «Боль и здоровье», «Люди», «Чувства» и другие.
2. Выбирает плитку: «Хочу пить», фото дочери, место на фигуре человека.
3. Приложение спрашивает: «Позвони Алии, пожалуйста. Так?» Она нажимает огромную зелёную «Да» или красную «Нет».
4. Фраза появляется крупно для собеседника и звучит. Кнопка «Ещё по-казахски» проигрывает «Әлияға қоңырау шалшы».
5. «Ещё что-то?» — можно продолжить мысль: «потому что…», «но…», «потом…».

Кнопки «Помогите» и «Сначала» видны всегда. «Помогите» включает сигнал и фразу «Помогите мне, пожалуйста!» на двух языках.

Срабатывает только одно спокойное нажатие: слишком короткое касание, двойное нажатие, ладонь и два пальца сразу не считаются. Всё управление — у левой руки (можно переключить на правую).

## Установка

Приложение — это сайт, который после первого открытия работает без сети.

1. Откройте адрес приложения на планшете в Safari (iPad) или Chrome (Android).
2. Нажмите «Поделиться» → «На экран „Домой“». Так приложение откроется на весь экран, а браузер будет бережнее хранить данные.
3. При первом запуске придумайте PIN из 4–8 цифр — он нужен для входа близких.
4. Выберите «Заполнить примером», если хотите сначала посмотреть, как всё работает, или «Начать с пустого», чтобы сразу вносить свою семью.
5. Откройте «Общие настройки» и проверьте надпись «Готово к работе без интернета». Первый раз приложение скачивает около 115 МБ, из них 90 МБ — голоса, поэтому лучше открыть его при Wi-Fi. После этого Wi-Fi можно выключать.
6. Там же нажмите «Проверить голос» — приложение скажет фразу на обоих языках и покажет, сколько секунд думает над фразой на этом планшете.

Где разместить сайт, решает тот, кто его собирает: подойдёт любой хостинг статических файлов (например, GitHub Pages) или компьютер в домашней сети. Данные бабушки на сервер не попадают никогда — сервер только один раз отдаёт файлы приложения.

## Вход для близких

Нажмите и держите правый верхний угол экрана 3 секунды (если выбрана правая рука — левый угол) и введите PIN. Бабушке этот жест не нужен, и случайно она его не сделает.

## Анкета: люди, места, вещи

Чем подробнее анкета, тем быстрее приложение угадывает.

- **Люди.** Имя по-русски и по-казахски так, как бабушка их называет («Алия» и «Әлия»), кем приходится, фото. Запишите имя своим голосом на обоих языках — запись звучит вместо синтеза, и знакомый голос узнать легче.
- **Места, вещи, еда, лекарства.** Название на двух языках и фото. У лекарств отметьте время приёма — утром приложение чаще будет думать об утренних таблетках. Диагнозы не нужны: приложение не даёт медицинских советов.
- **Воспоминания.** Важные события и темы, о которых она любит говорить.
- **Распорядок дня.** Что обычно бывает утром, днём, вечером и ночью. Например, ночью «повернуть меня» — «почти всегда».
- **Заметки дня.** «Звонила Алия», «завтра приедет Ерлан». Пока заметка действует, приложение чаще думает об этих людях.

Если фраза звучит с ошибкой в падеже, откройте карточку, раздел «Формы слова», и впишите правильную форму. Ручная форма всегда важнее правил.

## Её слова

Раздел «Её слова» — для слов, которые она говорит сама: «сен», «су», «жоқ».

1. Нажмите «Добавить», напишите слово и выберите язык.
2. Укажите, что оно может значить, и прикиньте веса. Например, «су»: «хочу пить» 0,6, «мне плохо» 0,3, «нужно в туалет» 0,1. Веса потом уточняются сами по истории.
3. Если она часто повторяет слово подряд («сен, сен, сен»), включите «Часто повторяет подряд» — тогда повтор не будет считаться усилением.
4. Запишите, как она его произносит, **5–10 раз** в обычной обстановке. Приложение сравнивает её речь только с её же записями.
5. Откройте «Тест распознавания» → «Проверить». Хорошо, если точность не ниже 85 %. Если какие-то слова путаются, добавьте им записей.

Если включён микрофон, у бабушки есть кнопка «Сказать»: она нажимает, говорит слово и замолкает. Если приложение не уверено, оно переспросит: «Вы сказали „сен“?» Слова, которые оно не узнало, попадают в «Прогресс речи» — их можно прослушать и добавить в словарь одним нажатием.

## Языки

Интерфейс для близких всегда на русском. В разделе «Языки» настраивается, как всё звучит для бабушки.

- **Основной язык** — на нём звучат вопросы, подсказки и итоговые фразы.
- **Режим звучания** — только русский, русский затем казахский («Вода. Су.»), казахский затем русский или только казахский. Задайте режим для всего сразу, потом для категорий (например, «Люди и семья» — казахский, затем русский), а для отдельной плитки — в её карточке.
- **Слово для развития** — такие слова всегда звучат на двух языках и попадают в занятия. Отметка есть в карточке человека, вещи и слова.
- **Род говорящего** — «я рада» или «я рад».
- **Обращение** — «принеси» или «принесите».

## Кнопки ответа

В разделе «Кнопки ответа» можно поменять цвет, значок и подпись «Да» и «Нет», включить третью кнопку «Почти» и записать её собственное слово — тогда при нажатии будет звучать её голос.

## Развитие речи

Кнопка «Развитие речи» внизу меню открывает занятие. Приложение показывает фото и произносит слово, бабушка повторяет, вы отмечаете: «сама», «с подсказкой», «не смогла».

- Если получилось само, в следующий раз подсказка будет меньше: сначала слово целиком, потом только первый слог, потом одна картинка.
- Трудные слова возвращаются в том же занятии, лёгкие — через несколько дней.
- В занятие попадают имена родных, слова для развития и слова из её словаря.

## История и «почему так»

В «Истории» — все подтверждённые сообщения с датой и числом шагов. Отметьте, повторила ли она фразу вслух и на каком языке, — это попадёт в «Прогресс речи». Кнопка «Почему так» показывает, какие нажатия, слова и ответы привели к догадке и с каким весом.

## Резервная копия

Раз в неделю нажимайте «Резервная копия» → «Сохранить копию» и храните файл `.golos` вне планшета: на компьютере, в облаке, на флешке. Если браузер очистит память или планшет сломается, «Восстановить из файла» вернёт всё: анкету, слова, записи голоса, историю. Приложение напомнит само, если копии нет больше недели.

## Если что-то не так

- **Нет звука.** Проверьте громкость. Звучат записи голосом близких, затем голос синтеза приложения (русский и казахский), затем встроенный голос планшета. Если в «Общих настройках» написано, что голос синтеза не скачан, откройте приложение при Wi-Fi.
- **Голос долго думает или говорит слишком быстро.** «Общие настройки» → «Проверить голос» покажет время. Сообщите тому, кто собирал приложение: голос и темп меняются при сборке.
- **Ударение в имени не там.** Карточка человека → «Ударение»: нажмите ударную гласную, затем «Послушать» и «Сохранить».
- **Имя всё равно звучит неправильно.** Запишите его своим голосом в карточке человека — запись всегда звучит вместо синтеза.
- **Не узнаёт её слова.** Запишите больше образцов в той обстановке, где она обычно говорит. Проверьте результат в «Тесте распознавания».
- **Часто угадывает не то.** Заполните распорядок дня и заметки, поправьте веса значений её слов. Если она часто нажимает не ту кнопку, это можно указать в «Общих настройках» — приложение раньше предложит выбор из картинок.

## Для разработчика

```bash
npm install
npm run dev        # разработка
npm run voices     # один раз: скачать голоса синтеза (voices.config.json) в public/voices/
npm run build      # статическая сборка в out/ и service worker
npm run check      # типы, модульные тесты, проверка отсутствия внешних сервисов
npm run sim        # симулятор: шаги до правильной фразы
npm run coverage   # покрытие движка
npm run e2e        # Playwright: планшет альбомно и портретно, телефон
```

- `engine/` — движок без зависимостей от интерфейса: онтология, вывод, вопросы, обучение, морфология русского и казахского, генерация фраз, распознавание слов, развитие речи, симулятор. Работает и в браузере, и в Node.
- `engine/data/` — фреймы, шаблоны фраз на двух языках и таблицы правдоподобия в JSON. Новая мысль добавляется без правки кода.
- `DECISIONS.md` — принятые решения и цифры симулятора, `TODO.md` — что нужно проверить людям, `docs/tts-comparison.md` — сравнение голосов синтеза.
- Синтез речи — Piper в браузере: onnxruntime-web (MIT), espeak-ng (GPL-3.0), голоса irina и raya (`voices.config.json`). Модели в git не хранятся.
