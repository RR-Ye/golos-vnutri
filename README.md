# Голос внутри

Инструмент общения для человека с афазией после инсульта. Работает на планшете без интернета, все данные хранятся только на устройстве.

Подробное руководство для близких появится в конце работы. Пока — для разработчика:

```bash
npm install
npm run dev      # разработка
npm run build    # статическая сборка в out/ + service worker
npm run check    # типы и тесты
```
